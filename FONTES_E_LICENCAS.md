
# Fontes e licenças da biblioteca

## wger
Base principal de exercícios. A API retorna dados, imagens, vídeos, autoria e licença individual de cada exercício. A licença é mostrada na tela de detalhes do GYM.

## Exercemus Exercises
Base de fallback de dados e vídeos. O projeto reúne exercícios de fontes abertas e preserva metadados de licença quando disponíveis.

O GYM não utiliza resultados aleatórios do Google como arquivos permanentes. A pesquisa do Google pode servir para conferência visual, mas cada imagem incorporada ao produto precisa ter licença de reutilização verificável.
