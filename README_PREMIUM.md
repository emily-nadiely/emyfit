# EmyFit Pro Premium v3.0

Versão premium do PWA de treino, com:

- onboarding e geração de plano;
- login e sincronização pelo Supabase;
- treino guiado com séries, carga, repetições e RIR;
- fadiga/recuperação muscular;
- cardio por aparelho;
- relatórios e evolução;
- ilustrações anatômicas aprovadas para Leg Press e Remada;
- novo ícone premium instalável.

## Atualização sem perder o Supabase

O pacote NÃO contém `config.js`, para não apagar suas credenciais.
Mantenha o `config.js` que já está no repositório.

## Publicação

1. Extraia o ZIP.
2. No GitHub, abra o repositório do EmyFit.
3. Use `Add file > Upload files`.
4. Envie todo o conteúdo extraído para a raiz.
5. Confirme a substituição dos arquivos.
6. Aguarde o GitHub Pages concluir a publicação.

## Atualização no celular

Desinstale a versão antiga do PWA e limpe os dados do site no Chrome quando o ícone ou o layout antigo continuar aparecendo.
