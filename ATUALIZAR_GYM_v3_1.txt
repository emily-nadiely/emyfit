COMO PUBLICAR
1. Extraia o ZIP.
2. Abra o repositório atual no GitHub.
3. Add file > Upload files.
4. Envie TODOS os arquivos e pastas de dentro da pasta GYM_Premium_v3_1.
5. NÃO apague nem substitua seu config.js já configurado no GitHub. Este pacote não contém config.js.
6. Faça o commit e aguarde o GitHub Pages ficar verde em Actions.
7. No celular, desinstale o PWA antigo, limpe os dados do site no Chrome e instale novamente.

OBSERVAÇÃO
Os dados continuam usando a mesma estrutura e as mesmas chaves internas, portanto o histórico e o Supabase não são renomeados nem apagados.
